# AP Computer Science Projects

A collection of Java projects created while learning core computer science ideas, from board games to data structures and small simulations.

## Browse the projects

There is no single hosted web demo because these projects are Java programs. You can browse the [source code and project folders](https://github.com/Av1Sharma/AP-ComputerScience), including:

- **Games:** Elevens, Minesweeper, Nim, and Tic-Tac-Toe
- **Algorithms and data:** Degrees of Kevin Bacon, SocialNet, and RFOS
- **Practice apps:** ShoppingCartManager

## What it uses

- **Java** for the programs and game logic.
- **The Java standard library** for basic input, collections, and user interface components.

## Run it yourself

Install a Java Development Kit (JDK), then clone the repository. Each folder is its own project and may have different classes to run. Open a project folder in an IDE such as IntelliJ IDEA, Eclipse, or BlueJ, select its main class, and press **Run**.

```bash
git clone https://github.com/Av1Sharma/AP-ComputerScience.git
cd AP-ComputerScience
```

For a command-line project, compile its Java files from that project’s folder and run the class containing `main`. Some assignments use starter classes or libraries; see the files in that folder for its entry point and requirements.
